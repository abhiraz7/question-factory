2 · Paste the AI's reply

Paste the whole reply from DeepSeek/ChatGPT/Claude. The parser reads the machine-readable markers first, and falls back to reading the visible SEO panel + HTML if a model ignored them — nothing is ever a dead end. This prompt asks the AI to teach the topic as thoroughly as it genuinely needs, which can run long, so on a phone the AI app itself may split its answer across several messages — that's expected, not an error. Paste each chunk here as it arrives, tick "This is a continuation," and tap Parse again after every chunk; the last chunk should end with the <<<END_PUBLISHER_NOTES>>> marker.

A .zip works too — e.g. the AI packaged its reply as separate SEO/body/publisher-notes files, or several numbered part files.
