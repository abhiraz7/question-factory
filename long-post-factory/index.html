1 · Build & copy the prompt

Builds a prompt entirely on this page — no master-prompt file is loaded, which keeps the prompt short. It casts the AI as four internal roles (teacher, examiner, note-maker, editor) for whichever exam you type (built-in personas for CTET / BPSC TRE / DSSSB TGT & PRT / UPTET / UP TGT / KVS / NVS / PGT / PRT — any other exam name still works, using a generic-but-real persona built from the name), and asks it to teach the topic as deeply as it genuinely needs — no fixed word count, no padding. The AI writes plain content inside {* type: title *} ... {* END *} blocks instead of hand-written styled HTML — far fewer output tokens, so it's less likely to run out mid-article. On mobile, a long reply may land in several messages — that's normal, see Step 2.

Key terms, definitions, and technical labels always stay in English regardless of this split — this only controls the explanations/tricks/teacher-talk prose.

📚 Reference sources for this run

Auto-picked from Subject (below) + a general list — always official/whitelisted sources. The AI is told to use these as supporting material only: never copy source text, never invent claims beyond them.

📱 Copy the prompt in parts (opens automatically after building — use this on mobile)

Mobile keyboards (Gboard/Samsung/SwiftKey clipboard) and mobile browsers silently truncate a single copy past roughly 8,000–10,000 characters, so the prompt is split into only as many parts as it actually needs to stay under that per-part. Tap "Build prompt" above first, then use these buttons in order — paste each one as its own message in the SAME chat before sending the next. Tell the AI to wait until you say "generation config: go" if it starts replying early. On a PC, skip this and use "Copy whole prompt" instead.

2 · Paste the AI's reply

Paste the whole reply from DeepSeek/ChatGPT/Claude — it should be plain Markdown (frontmatter + ## headings + fenced ```type blocks, no HTML, no {* *} tags). The parser reads that format first, and falls back to the older machine-readable markers or a plain labeled panel if a model used those instead — nothing is ever a dead end. This prompt asks the AI to teach the topic as thoroughly as it genuinely needs, which can run long, so on a phone the AI app itself may split its answer across several messages — that's expected, not an error. Paste each chunk here as it arrives, tick "This is a continuation," and tap Parse again after every chunk; the last chunk should end with the <!-- PUBLISHER NOTES --> section.
